Splitting the code so the bot and simulator can't drift

The handover strongly recommends moving the night-resolution code out of the simulator into a shared module. The five connection points below (I've called them ports) are my addition. They're how one engine can run in both places: the engine only uses these five, and the bot and the simulator each plug in their own version.

Port my additionWhat it hidesBot plugs inSimulator plugs in
Messengerhow messages reach playersDiscordprinted to screen

EventLogwhere events goseason.jsonl on diskmemory, or --log file
